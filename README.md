# Marktkrant Tholen — proefversie

Open `index.html` in een moderne browser om de proefversie te bekijken.

## Beheren

Klik rechtsboven op **Beheer** en gebruik voor deze proefversie de code `marktkrant2026`. Daar kunt u:

- artikelen toevoegen, aanpassen en van een afbeelding voorzien;
- categorieën beheren;
- ontvangen proefbestellingen als CSV-bestand downloaden.

Ook kunt u bij elke categorie een sponsornaam, toelichting en logo toevoegen. Die vermelding verschijnt wanneer de bezoeker die categorie kiest.

De gegevens zijn in deze demo bewust alleen in de browser opgeslagen. Daardoor is dit een ontwerp- en gebruikersproef, geen website die al bestellingen van verschillende bezoekers centraal ontvangt. De beheercode vormt hier dus alleen een zichtbare testafscherming; hij is geen veilige productiebeveiliging.

## Voor de echte site

De volgende stap is een beheerde online versie met een centrale database, beveiligde beheerlogin, e-mailbevestigingen en een bestellingenoverzicht. De artikelen, categorieën en vormgeving uit deze proef kunnen daarvoor als uitgangspunt dienen.
